# C12A-M01 — Meaning and reference

Baseline allocation: **20 hours**. Prerequisites: Courses 1, 2 first-order language/semantics, 5 and 7; prior modules in this option (except M01, also usable as the PC-28 foundation).

## Guiding question and outcomes

How can an identity inform us when both names refer to the same thing?

By the end: Distinguish sense, reference and a private image; formalize existence and uniqueness; explain negation scope and a limit of the analysis.

## Teaching explanation

Frege begins from the contrast between an uninformative self-identity and an identity that connects different ways of identifying one object. A reference-only explanation misses their different cognitive value. Sense is a mode of presentation, not simply whatever image happens to occur to a speaker. Distinct senses can present the same referent; understanding an expression does not guarantee that it refers. For sentences, Frege connects sense with a thought and reference with truth value, which helps explain substitution in ordinary contexts but creates a special problem for reports of belief. Do not infer that substituting co-referring names preserves every belief report.

Russell instead treats a definite description as part of a quantified sentence. “The F is G” requires an F, only one F, and its being G. A description need not function as a disguised name for a mysterious nonexistent object. Negation can deny that whole claim or attach only to G within it. The difference explains why “the present king is not bald” is ambiguous on this analysis. Formalization makes commitments explicit; it does not by itself settle how an actual speaker uses a description, what information the audience has, or whether Russell’s analysis is the best semantic theory.

## Worked practice example

Invented example: the first person to sign register R is also the keeper of key K, but Mira knows only the first description. Learning the identity can change Mira’s information without adding a second person. If F(x) means “x is first signer” and G(x) means “x holds K,” Russell’s analysis is ∃x(Fx ∧ ∀y(Fy → y=x) ∧ Gx). This states existence, uniqueness and possession separately. If two people sign simultaneously, the description’s uniqueness condition fails; that does not imply that nobody holds the key.

## Supported practice artifact

P01: Submit a 500-word identity explanation and two formalizations of “The sole curator is not asleep,” one with narrow and one with wide negation. Test each in a model with no curator and in a model with one awake curator. Back-translate every quantifier. Explain one conversational limitation.

Criteria: answer the stated question, make the key distinction explicit, connect reasons to the conclusion, and identify the actual source of attributed claims. Label invented examples. Keep your first attempt and help log.

## Independent changed case

I01: A town has two equally ranked archivists and no mayor. Evaluate “The mayor signed the register” and the two readings of “The mayor did not sign the register.” Then explain how “Orion is Vale” could inform a resident although both names designate the same inventor. Submit 350–450 words and formulas.

Use assigned sources and ordinary access aids, but no live content help, model answers or examiner notes. Declare prior exposure. Neutral criteria: faithful use of the assigned concepts; a justified inference; an identified limitation; traceable attribution. Freeze the response before feedback. If exposed, use the relevant alternate in assessment.md, or the examiner's unused changed-case procedure for a nonessential subskill.
