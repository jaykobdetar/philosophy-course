## Teaching explanation

A category error treats something as belonging to a logical type it does not have. Ryle’s diagnosis attacks a picture in which mental life is an extra inner arena alongside bodily activity, with the same general explanatory shape. That diagnosis is stronger than observing correlations, but it is not automatically the claim that every mental term means an observable movement. The task is to show where the mistaken classification does argumentative work.

Putnam asks what it would be for pain to be a mental state identified through its functional organization. A functional specification relates input, internal states and output; it is not a list of overt behaviors alone. Two systems could implement the same organization in physically different materials. If one mental type has different physical realizers, identifying it with a single narrowly described neural type becomes problematic. This is a challenge to a specific type identity, not an immediate refutation of physicalism, token identity, or dependence on a physical realization. Equally, merely calling two devices “pain detectors” does not show that either has pain. Distinguish the stipulated functional role from the contested identification of that role with experience.

## Worked practice example

Invented example: an underwater robot and a land robot each withdraw from damaging inputs, store the event, and alter future plans. One uses fluid pressure, the other silicon. This supports a conditional multiple-realization argument if their relevant causal organization is genuinely the same. It does not establish that either feels pain. A device that only prints “ouch” lacks the stipulated memory and planning links.
