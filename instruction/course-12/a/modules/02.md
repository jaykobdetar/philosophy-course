## Guiding question and outcomes

Can a name keep its referent when the descriptions associated with it change?

By the end: Distinguish rigid designation, necessity and a priori knowledge; reconstruct one Lecture I challenge to descriptivism.

## Teaching explanation

A rigid designator designates the same object across relevant possible situations where that object exists. This concerns how we speak about counterfactual situations, not a method for recognizing objects in them. A description such as “the first elected chair” can pick out different people in different situations; that is one reason replacing a name with a familiar description can change a modal claim.

Necessity concerns how things could have been; a priori status concerns how a claim can be known. Certainty describes an epistemic attitude and guarantees neither. The distinction prevents a common shortcut: because discovering an identity was difficult, it does not follow that the identity could have been false. Lecture I also separates using a description to fix a reference from making the description synonymous with a name. A stipulated introduction can identify the intended person without making every later use mean the identifying description. Keep an objection proportional: a counterexample to one descriptive account does not, without further argument, refute every cluster theory or establish an entire causal account of naming.

## Worked practice example

Invented example: “Luma” is introduced as the name of the actual winner of a race. In a counterfactual situation Luma loses. “Luma loses” can concern that same runner; “the winner loses” can instead switch reference or express an inconsistent description depending on scope. The naming ceremony fixes whom we discuss; it does not make victory part of the person’s essence.
