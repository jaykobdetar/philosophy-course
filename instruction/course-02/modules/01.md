## Explanation and worked case

An argument presents some sentences as reasons for another. Its conclusion may be placed first in English; “because” normally introduces a reason, while “therefore” normally introduces a conclusion. Indicator words help locate roles but cannot determine whether the reasons actually support the conclusion.

Truth concerns a sentence in a case. Validity concerns whether an argument has **any** admissible case with all premises true and its conclusion false. To show invalidity, supply exactly that combination. A false premise in the actual world is not a counterexample. A valid form can be used with false premises; soundness additionally requires true premises. Establishing premise truth often requires history, observation or ethical argument beyond formal logic.

Invented example: “Every item in Box A is blue. The cube is in Box A. Therefore the cube is blue.” If both premises are true, the conclusion must be true. This is valid even if the box actually contains a red cube, in which case its first premise is false and it is unsound. Reversing the second premise and conclusion gives “Every item in Box A is blue; the cube is blue; so the cube is in Box A.” Imagine a blue cube outside the box. Both premises can be true and the conclusion false. This countercase attacks the inference, not a person's reliability.

Consistency here concerns whether claims can all hold together; later chapters distinguish semantic joint satisfiability from proof-theoretic consistency. Equivalence requires the same truth value in every relevant case, not merely agreement today. Two incompatible sentences need not each be impossible: “the switch is on” and “the switch is off” can each be true in different cases, but cannot both be true at the same time under the stipulated binary-switch interpretation. Distinguish conceptual constraints in English from unrestricted assignments of truth values introduced later. An always-observed fact need not be necessary.
