## Proofs keep track of dependence

A proof says not only that a conclusion follows but how each line depends on available reasons. Premises remain available. An assumption temporarily opens a subproof. Closing it prevents later direct access to its interior lines; certain rules can cite the entire subproof. From an assumed P followed by Q, conditional introduction concludes `P → Q` outside, not Q alone. Work backward from a conclusion's main connective and forward from available premises. A conditional conclusion suggests assuming its antecedent; a conjunction suggests two goals; a disjunctive premise suggests two cases with the same endpoint.

Invented worked proof of `P → Q, Q → R ⊢ P → R`:

```text
1   P → Q       PR
2   Q → R       PR
3 | P           AS
4 | Q           →E 1,3
5 | R           →E 2,4
6   P → R       →I 3–5
```

Lines 4 and 5 use conditionals whose antecedents are available. The result on line 5 depends on assumption 3, so line 6 exports only the conditional. Writing `R, R 5` after line 6 would illegally reach into the closed subproof. Nested assumptions must close from inside outward.

## One instance of every new rule

Work each instance on paper with line numbers, then explain it. These are rule demonstrations; the independent bank follows below. Letters stand for sentences, including compound ones.

| Rule | Concrete instance and reason |
| --- | --- |
| R | An available `P` can be repeated as `P`; it must still be accessible. |
| ∧E | From `P ∧ Q` obtain `P` (or `Q`), since both were asserted. |
| ∧I | From `P` and `Q` obtain `P ∧ Q`; both lines must be accessible. |
| →E | From `P → Q` and `P` obtain `Q`; `Q` alone never permits the reverse inference. |
| →I | Subproof `AS P; P (R)` yields `P → P`; discharge P. |
| ↔E | From `P ↔ Q` and `Q` obtain `P` (and conversely with P). |
| ↔I | Subproof `AS P∧Q; Q; P; Q∧P` and subproof `AS Q∧P; P; Q; P∧Q` yield `(P∧Q) ↔ (Q∧P)`; cite both complete ranges. |
| ∨I | From `P` obtain `P ∨ Q` or `Q ∨ P`. The unknown disjunct need not be established. |
| ∨E | Given `P∨Q, P→R, Q→R`, subproof `AS P; R (→E)` and subproof `AS Q; R (→E)` yield R. Both branches end in the same R. |
| ¬E | From `P` and `¬P` obtain `⊥`. This label does **not** mean double-negation elimination in this calculus. |
| ¬I | Given `P→Q, ¬Q`, open `AS P; Q (→E); ⊥ (¬E)` and close with `¬P`. |
| IP | Given `¬¬P`, open `AS ¬P; ⊥ (¬E)` and close with P. This is a classical rule. |
| X | From an accessible `⊥` infer Q; do not invent a contradiction to use it. |
| DS | From `P∨Q, ¬P` infer Q (or from `P∨Q, ¬Q` infer P). |
| MT | From `P→Q, ¬Q` infer `¬P`. Expand it into the ¬I demonstration above to see its basis. |
| DNE | From `¬¬P` infer P; the IP demonstration supplies an expansion. |
| LEM | From `P→R, ¬P→R`, use subproofs `AS P; R` and `AS ¬P; R` to conclude R. **The book's LEM rule cites two subproofs**, not a premise-free line `P∨¬P`. |
| DeM | The allowed whole-formula pairs are `¬(P∧Q)` / `¬P∨¬Q`, and `¬(P∨Q)` / `¬P∧¬Q`, in either direction. Explain one pair by a truth table; this is not permission for arbitrary replacement inside a formula. |

Faded proof: premises `P ∨ Q, P → R, Q → R`; lines 4–5 are `AS P; ___`, lines 6–7 are `AS Q; ___`, line 8 is `___, ∨E ___`. Fill formulas and citations, then write P07 independently.

`Γ ⊢ C` says a derivation exists from premises Γ; `Γ ⊨ C` says no interpretation of the relevant kind refutes the inference. Soundness of the calculus goes from derivability to entailment; completeness goes back. These are metatheoretic claims, distinct from soundness of an argument (validity plus true premises). A failed proof search establishes neither invalidity nor incompleteness. A theorem has a proof with no undischarged premises; an assumption introduced and later discharged is compatible with theoremhood. A derived rule abbreviates a proof pattern in the basic rules; it is not a new unsupported principle.
