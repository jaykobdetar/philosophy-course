Pinned local sources: [README](../README.md).

**18 hours:** reading 4; guided tables 4; independent bank/check 4; feedback 2; revision 3; retrieval including M2-D 1.

## Semantics in steps

A valuation assigns T or F to each sentence letter. A complete table for n distinct letters has 2^n rows. Fill constituent columns before the main connective. `¬A` is true when A is false; `A ∧ B` when both are true; `A ∨ B` when at least one is true; `A → B` except when A is true and B false; `A ↔ B` when they agree. One assignment must be used consistently throughout a row. A letter occurring twice does not create two independent inputs.

Invented worked example: test `P → Q, Q ∴ P`.

| P | Q | P → Q | Both premises true? | Conclusion P |
| --- | --- | --- | --- | --- |
| T | T | T | yes | T |
| T | F | F | no | T |
| F | T | T | yes | F |
| F | F | T | no | F |

The third row is decisive. In English, the stated consequence Q occurs even though P does not; the conditional never promised that P was the only route to Q. The fourth row is irrelevant to invalidity because Q, a premise, is false. A countervaluation must preserve **all** premises.

A tautology is true on every row, a contradiction on none, a contingent formula on some but not all. A set is jointly satisfiable if one row makes all its members true. Two formulas are equivalent if their final columns match on every row. An argument is valid if no row has true premises and false conclusion. In particular inconsistent premises entail every conclusion, since there is no true-premise row. That formal fact does not make the premises credible.

For a partial table, start from the failure you seek and work inward. To refute `(P ∧ Q) → R`, set R=F and P=Q=T. For a conclusion `P ∨ Q` to be false, both P and Q must be false; propagate these constraints into the premises. A failed branch is not a completed validity test if another branch remains. A single witness establishes satisfiability or invalidity; a tautology/validity claim needs exhaustive coverage or a sound general argument.

TFL treats whole atomic sentences as independent. It can miss conceptual entailment such as “this shape is a square, so it has four sides,” unless the relevant connection is represented. A table's countervaluation may not be a coherent interpretation of the original words. Also, truth functionality omits causal, temporal and conversational information. Always state whether a result concerns the formal model or the English argument.
