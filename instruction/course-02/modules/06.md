## Interpreting a formula

An interpretation supplies a nonempty domain, a referent for each relevant name, and an extension for each predicate: a set of objects for a one-place predicate or ordered tuples for a relation. Any unlisted tuple is false. Identity is actual sameness in the domain; it is not a freely chosen relation. Names may coincide, and the domain need not contain only named objects.

Invented worked model: domain `{0,1}`, `a=0`, `b=1`, F-extension `{0}`, G-extension `{0,1}`, R-extension `{(0,1),(1,0)}`. Then `F(a)` is true, `F(b)` false, and `R(a,b)` true. `∀x(F(x) → G(x))` is true: x=0 has both properties, while x=1 makes the antecedent false. `∃x(F(x) ∧ G(x))` is true with witness 0. `∀x∃y R(x,y)` is true, using y=1 when x=0 and y=0 when x=1. `∃y∀x R(x,y)` is false, since neither 0 nor 1 receives both arrows. These evaluations enumerate every relevant object, not just the named one you happen to notice.

For a countermodel to an argument, aim for every premise true and the conclusion false. If the conclusion is universal, choose a failing object. If existential, make every candidate fail. Specify the entire finite extension, then independently evaluate every sentence. For `∀x F(x) ∴ F(a)`, no interpretation can refute the inference: a refers to a domain member, and the premise covers every domain member. This is general semantic reasoning. Failing to find a countermodel among domains of size one or two would not by itself establish validity; first-order interpretations may be larger or infinite.

Extensional FOL records which objects satisfy a predicate. It does not encode every aspect of a predicate's meaning or how an object is described in a belief context. `a=b` licenses replacement in the extensional language; it does not directly license substitution in “someone believes that…” treated as ordinary English. Similarly, an arbitrary relation symbol is not automatically transitive because you intended “older than.” State a premise `∀x∀y∀z((R(x,y) ∧ R(y,z)) → R(x,z))` if transitivity must play a formal role.

Reflexive means each object relates to itself. Symmetric means every arrow has its reverse. Transitive means every two-arrow path has a shortcut arrow. Antisymmetric means a two-way pair can only occur between the same object. Antisymmetric does not mean “never symmetric”; the identity relation is both. Empty relations are symmetric and transitive but not reflexive on a nonempty domain.
