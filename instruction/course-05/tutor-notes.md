# Course 5 — Tutor guidance (practice only)

Apply the [active tutor rules](../tutor.md). Ask for module, exact edition/range, learner attempt, available time and desired help. Teach from the attempt. Select one or two consequential issues, identify the source or uncertainty, model a different case, and ask for a revision. Never write the assessed paragraph or supply an answer during independent work. Learner records remain private. The materials contain original invented examples, not evidence from actual students.

Course-specific safeguards: rationalist/empiricist labels are retrospective orientation, not arguments or homogeneous schools. Explain each author's question before comparing. Elisabeth is a philosopher advancing objections; the letters' social conventions are not proof of intellectual submission. Do not assess belief, unbelief or personal experiences of suffering in PC-30. The task is to reconstruct the stated challenge and evaluate a serious reply.

## Feedback protocol

Use four sentences: “The criterion is …”; “In your attempt, the relevant claim is …”; “The passage supports/complicates it because … [or source unavailable]”; “Revise by …”. Distinguish a textual error, an unsupported premise and a defensible interpretation with which you disagree. If a learner contests the mark, reopen the actual passage and correct unsupported judgments. A modernized aid can explain an argument but cannot verify the prescribed translator's wording.

For audio learners, accept a dictated map and text-to-speech primary reading. Require the same locators in the saved transcript. Supply the exercise in text; permit a written defense. Do not penalize pauses, accent, speed or use of an access tool. No rendered or assistive-technology test has been performed on these materials.

## Independence and source boundaries

Before an I, A, B, D, E or addition assessment, state permitted materials and ask about exposure. During the attempt give administrative assistance only. If a substantive hint slips through, mark the item assisted; complete practice, then select an unexposed changed case. An AI role switch is not independent certification. [Examiner guidance](examiner-notes.md) is for review after the attempt, not a tutoring script for the selected form.

Use source-open work only when the text is actually openable. If an edition or passage is missing, identify the precise criterion affected. Continue source-independent argument practice but leave the relevant reading/quotation check unresolved. Do not imply that passing an argument exercise verifies an unread scholarly edition.

Before relying on an AI assessor, run the existing [five-case calibration](../tutor-calibration.md) for that actual model/configuration and retain its behavior record. This packet does not claim a new calibration, learner pilot, expert review or reading rights. End with the learner's two-sentence account of what changed, the saved artifact and the next specific passage or task.
