Teaching and assessment design is complete; reading and exact-wording judgments using those editions remain access-dependent. A learner can study with the explicitly identified provisional alternatives, recording the edition actually used. This does not establish equivalence or silently amend the prescribed editions. Secure the prescribed copy before submitting claims about its wording or pagination. No AT/page crosswalk is supplied for Veitch.

Each module includes reading, original teaching, a different worked case, a bounded practice task, an independent changed case, repair and delayed retrieval. Its hours include its own delayed retrieval, normally 7–14 days after practice; these can overlap the calendar of the next module without being billed there. Module 8's course delayed check is a separate occasion. Opening Course 1 sessions retain their original credit: Module 1 explicitly budgets rereading Descartes and new analysis, not a second charge for Course 1 attendance. No new Course 5 opening sessions existed to preserve.

Audio route: listen to a lawful recording or text-to-speech of the exact assigned range, pause at each argument boundary, dictate a numbered map, and return to the text for every citation. The written equivalent is the same range with an annotated map. Audio performance, accent and speed are not assessed. A timestamp identifies an audio location only; add the text's meditation, letter date, proposition or section plus the actual edition page if quoting. Unverified OCR is unsuitable for exact quotations. Break a 90-minute assessment into prearranged accessible blocks with the same total working time; record conditions. Text responses can replace speech.

Completion means evidence in every essential row, the revised essay and source audit, a responsive defense, and delayed transfer. It does not mean agreement with any philosopher or religious conclusion. Timing is an authoring allocation, not learner-pilot evidence. No learner pilot, external expert validation, reproduction permission, or rendered accessibility validation is claimed.
