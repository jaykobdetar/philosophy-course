# Course 14 outcome and evidence map

Read with the [shared rubric](../../current/assessment.md), especially “Observable rubric anchors” and “Course 14.” Each row requires a satisfactory practice artifact and independently competent evidence. Date each judgment and cite actual sections; leave blank until work exists. The grouped source grid is expanded here so proposal, integrity, reasoning, revision, response and transfer are each visible.

A single artifact may inform several rows when actual passages meet each criterion; its hours count once. M7 defense supplies independent objection/reply and supports method/reasoning judgments. It cannot replace the later D8 occasion. A polished final paper without process/source/independence evidence leaves rows unresolved.

Prerequisite check: retain an independently produced reconstruction, a reliable attribution record, a substantive revision, one source-sensitive interpretation, and the Course 13 research/source evidence. If one is absent, identify the original course repair before claiming readiness; no arbitrary aggregate score substitutes for it. Final portfolio breadth is specified in M8 and in the current course source.
