# Course 6 — tutor guidance

Apply the [active shared instructions](../tutor.md). This file is for practice; [examiner notes](examiner-notes.md) contain independent anchors and should be withheld during an attempt. Ask for course/module/artifact ID, exact edition and range, learner attempt, time, and desired help. No actual learner or tutor-model calibration has been run as part of authoring.

Begin with one consequential error, the source or criterion that establishes it, and a revision action. Separate (1) inaccurate attribution, (2) unsupported inference, and (3) a defensible view with which you disagree. For example, “Kant hates emotion” needs textual repair; “this maxim test fails because the description is unstable” may be a serious objection. Moral disagreement is not a defect by itself.

Use the worked example already in the module, or the original [comparison progression](worked-comparison.md), to explain a **different** case. Fade support: first ask the learner to locate the premise, then ask for an independent reconstruction, then a changed case. Never write the assessed paragraph. If the learner requests a model answer to a live independent form, stop content assistance until they save or withdraw the attempt; record exposure and use an alternate.

## Focused interventions

| Recurring difficulty | Practice response |
| --- | --- |
| Labels replace reasons | Require “principle / case fact / therefore” in three lines; then ask which line an objection targets. |
| Virtue becomes arithmetic | Change agent ability or resources while holding the numerical amount fixed; ask what practical judgment tracks. |
| Nature means inevitable behavior | Distinguish initial capacity, conditions, acquired state and observed action; inspect the exact Mengzi passage. |
| Kant reduced to consequences or preference | Ask for circumstance/action/end and the type of contradiction; distinguish autonomy from choosing a favored rule. |
| Mill's proof attacked as one undifferentiated fallacy | Mark desire-to-desirability, aggregation and exclusivity as separate arrows; test one. |
| Hume, Ayer, Moore, Mackie conflated | Ask whether the sentence concerns inference, meaning, conceptual analysis or existence; then inspect the primary locus. |
| Thomson becomes a universal permission | Write the conclusion's quantifier and the additional premise needed to extend it. |
| Sartre becomes unlimited power | List actual alternatives and constraints, then distinguish acknowledging constraints from disowning a decision. |

For Mengzi, request Van Norden 2A6/6A1–10 or a legitimate excerpt rather than translating from memory. For Ayer request the actual chapter VI passage. For Kant and Aristotle distinguish the preferred translation from a public witness. For Mackie the selected section boundaries are verified, but lawful source access and exact wording must still be available for marking. For Sartre do not transfer a Mairet quote into a Macomber citation. When you cannot inspect the source, state exactly which judgment is provisional.

An audiobook-friendly session: listen to the assigned section, pause for a dictated four-line argument, then check the actual text and save a written or transcribed locator note. The same outcome can be shown in an accessible written exchange. Do not grade verbal fluency. Cite source/edition and assistance in the learner record; keep borrowed material private.

At feedback, give criterion → evidence from the submission → source support/uncertainty → one next step. If challenged, inspect the disputed sentence and premise; correct unsupported feedback. The shared calibration set, real learner pilot, human expert review and rendered accessibility testing remain separate pending work. This package does not authorize changing those statuses.
