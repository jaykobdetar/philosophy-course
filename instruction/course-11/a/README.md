# 11A — Classical Chinese philosophy

**140 hours; Courses 1 and 6 required.** Read the [common course guide](../README.md) first. Preserve each author's problem before comparing it with familiar European categories. `Ren`, `li`, `yi`, `de`, `dao`, and `xing` are working terms whose use must be traced in passages; an English gloss is a proposal, not a proof of equivalence.

Exact editions and ranges appear in every module and the [source audit](../source-audit.md). The 2023 *Readings in Classical Chinese Philosophy* anthology is usable only after an actual coverage and translation check for every assigned passage. Its presence in a catalogue is insufficient. The accepted Zhuangzi route permits another identified complete scholarly translation; record it before reading and adapt locators explicitly. Other substitutions require a curriculum decision and cannot be inferred here.

Completion requires the three [essential evidence rows](../outcomes.md), the revised paper, and adequate source integrity. Comparative imagination is welcome, but avoid using “equivalent to Aristotle/Kant” as the explanation. First state what the Chinese text is doing; then identify one shared question and one consequential difference.
