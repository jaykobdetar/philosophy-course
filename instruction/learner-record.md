# Private learner record template

Copy this template into a local `learner/` directory. That directory is ignored by Git; do not commit personal drafts, source excerpts from restricted readings, or assessment responses to a distributable branch.

## One routine progress entry

```text
Curriculum: 2026-10-13-r0
Course/option and task ID:
Date and focused time (approximate):
Work file link or local filename:
What I learned or still cannot do (one sentence):
Next small task and reading locator:
```

## Substantive assignment or independent check

```text
Course/option, task ID, and outcome IDs:
Source edition, translation, exact range, URL or local loan note:
Original attempt file and date (retain unchanged):
Allowed help; actual AI/human/tool help; prior exposure to this task:
Feedback: criterion, evidence, source passage, uncertainty:
Revision file and two important changes:
Fresh independent check: form, permitted materials, assistance, result:
Delayed changed case and date (when due):
Criterion readiness: supported / needs repair / unresolved, with evidence:
Next task:
```

For a computer activity, keep the existing four-part record: input passage/case; what changed; resulting map/table/proof; and two sentences on what the change shows and does not show. Paper is equivalent. A routine day does not require filling every substantive field.

After a break, read the last next-step line, attempt one short retrieval prompt, repair only a needed prerequisite, and continue. Missed calendar weeks do not create a backlog penalty.
