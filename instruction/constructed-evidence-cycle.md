# Constructed evidence and review cycle

This is a **fictional demonstration**, not learner data, a tutor test or a pilot result. It shows how one Course 1 reasoning criterion can be traced from an untouched attempt through feedback, revision, changed-case checks and a review challenge. The case sentences are original, not quotations from [OpenStax 5.3](https://openstax.org/books/introduction-philosophy/pages/5-3-arguments), which supplies the premise/conclusion method.

| Record field | Constructed entry |
| --- | --- |
| Task and source | `C01-S02`, identify a claim, reason and missing assumption after OpenStax 5.3. |
| Untouched attempt | “The library should stay open later because evening classes need it.” Retain this exact text; do not overwrite it with the revision. |
| Assistance and exposure | Fictional learner has seen the session instructions. Tutor may ask about the link between evening classes and library use. No paragraph was written by a tutor. |
| Criterion feedback | The claim is clear, but “evening classes need it” leaves an empirical premise unstated. Ask who needs access after class and what existing hours prevent. Do not assume that a favored policy is true merely because the inference is clearer. |
| Revision | “For students whose evening classes end after the library closes, later library hours would make on-site study possible, provided they lack an equivalent study space. The college should test actual demand before extending every evening.” |
| Revision memo | The learner names a narrower group, an access premise and one possible defeater. The policy conclusion is qualified. This repairs the stated reasoning issue; it does not verify actual demand. |
| Fresh changed case | “If the gallery is open, its lights are on. Its lights are on. Therefore it is open.” Independent response: a closed gallery with cleaning lights on makes the premises true and conclusion false. Record that this form was not rehearsed in feedback; if it was, select another form. |
| Delayed changed case | Four to six weeks later: “Only holders of an active pass may enter. Jules was admitted. What follows?” An independent response says Jules had an active pass under the stated rule, while the rule alone does not show whether admission was fair. Record actual assistance and time. |
| Review challenge | If a tutor marks the revised library claim “wrong” because late hours are costly, request the criterion, the factual evidence about costs and the inference alleged to fail. A reviewer may call the policy empirically unresolved while still judging the conditional reasoning competent. Keep both the challenge and resolution. |
| Readiness | Fictional example: reasoning criterion supported by the two changed forms; empirical library claim unresolved. **No actual learner readiness is established.** |

In a real record, attach original and revision filenames, edition/range, actual dates and focused minutes, feedback text, assistance disclosure, independent prompts and the review resolution. Store that personal record in ignored `learner/`, never in the repository's teaching package.
