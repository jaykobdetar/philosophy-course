# Course 1 opening release

**Status:** study-ready for the first four 90-minute sessions (six hours of Course 1's 120-hour source baseline). **Not piloted.** The remaining modules in the [full Course 1 page](../../current/courses/01.md) are specified, but do not yet have the same packet-level feedback and independent checks. Do not call the whole course study-ready.

Start with [Session 1](sessions/01.md), then [2](sessions/02.md), [3](sessions/03.md), and [4](sessions/04.md). Each may be split or extended; record actual focused time. [Reading readiness](../../current/readiness/course-01.md) states online and local access. Readings from outside this repository require an internet connection; do not assume that possession of an unmarked local translation supplies scholarly locators.

Use [the active tutor instructions](../tutor.md) for practice and [the learner evidence template](../learner-record.md) to save an untouched attempt, help received, revision, and next step. [Examiner notes](examiner-notes.md) give feedback anchors; keep them out of the tutor's practice context if possible. A real learner pilot is still required before claiming these sessions are piloted or expanding their pattern across all courses.

Use the [opening assessment forms](assessment.md) for fresh and delayed work, and the [review queue](review-queue.md) for targeted repair. The [pilot protocol](../PILOT_PROTOCOL.md) is ready for an actual learner but has not been run.

| Session | Main outcome | Reading | Output | Credit |
| --- | --- | --- | --- | --- |
| 1 | Attribute and paraphrase a claim | OpenStax 2.5; *Euthyphro* 2a–before 5d | Untouched 120-word paraphrase and claim/reaction distinction | 90 min to Module 1 |
| 2 | Find premises, conclusions, and assumptions | OpenStax 5.3 | Four argument reconstructions and one paragraph revision | 70 min Module 2; 20 min Module 3 |
| 3 | Test validity, soundness, conditions, and counterexamples | OpenStax 5.2 and 5.3 | Four explained cases and one near-case | 90 min Module 2 |
| 4 | Distinguish an example from a definition | *Euthyphro* 5d–before 8b | Locator notes, argument map, 150-word explanation | 90 min Module 4 |

Continue the rest of Modules 1–3 after Session 4, then complete Module 4. Revisit the full dialogue for a **new task**; the preview is already credited and is not assigned again as extra homework. Do not take the original fifteen-unit Introduction gate or its numerical certification rule.
