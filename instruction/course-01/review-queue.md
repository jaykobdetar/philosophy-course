# Course 1 retrieval and targeted repair

Use a short queue entry only when an error recurs. Record: outcome ID, the specific error, the source or reasoning form to revisit, one repair task, date for a different recheck, and evidence link. Clear the item when the fresh check supports the criterion; do not create an accumulating hidden course.

| Error seen | Small repair | Different recheck |
| --- | --- | --- |
| Speaker or claim confused | Reread the marked 4b–5c exchange, write one attributed sentence and one question | Attribute a different speaker's claim in 5d–8b |
| Conclusion mistaken for a premise | Reconstruct one Session 2 argument with numbered premises | New argument with conclusion first |
| Converse/necessary condition reversed | Draw a two-case table for the rule | New card, entry, or archive condition with different wording |
| Example treated as definition | State one category, one instance and one rule that covers further instances | New nonreligious category and borderline case |

At the next study session, spend a few minutes retrieving one item before rereading, then check the result. After an interruption, read the last next-step note, attempt one queue item, repair only needed prerequisites, and resume. Missing calendar weeks does not erase completed work or add debt hours.


## Later-course repairs

Use the same compact record for later modules. All ordinary repairs occupy the module feedback/revision allocation, Module 11 remediation, or Module 12 consolidation. Record extra time explicitly if those budgets are exhausted.

| Recurring gap | Bounded repair | Evidence for closing the item |
| --- | --- | --- |
| Approval treated as explanation (M04) | Mark both directions of “because” at 10a–11b and compare them with a new institutional status | Uncoached changed case distinguishes coextension from explanation |
| Inquiry or doubt overstated (M05–M07) | List what the speaker claims, suspends, and leaves open at one exact passage | A different passage reconstruction preserves the limits |
| Counterexample lacks a required condition (M08) | Fill truth/belief/justification/ground cells before judging knowledge | Fresh case preserves all proposed conditions and identifies the alleged failure |
| Singer principles conflated (M09) | Write each stopping condition separately using pp. 231 and 241 | Changed case distinguishes moral cost, preventability, and other agents' actual contributions |
| Essay objection missed (M10–M11) | Identify the attacked premise and write one direct response or scope revision | Unrehearsed objection answered with reasons and checked attribution |
| Citation or quotation unsupported | Reopen the actual edition and repair only the unsupported wording/locator | Every attributed claim in the revised passage is traceable; fresh source task follows if needed |

The alternate forms and diagnostic anchors are in [assessment](assessment.md) and [examiner notes](examiner-notes.md). Keep their answers closed during the new attempt. Missing evidence stays unresolved; a coached revision is not a fresh recheck.
