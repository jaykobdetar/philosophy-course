# C01-M02 — Arguments and definitions

**Planned allocation: 8 focused hours (480 minutes), within the 120-hour baseline.**

**Guiding question:** What must be true for these reasons to support this conclusion?

**Prerequisites and outcomes:** Module 1 attribution; Sessions 2–3. Reconstruct six arguments, distinguish necessary and sufficient conditions, produce four condition tests, and explain validity versus soundness (O2–O3).

**Assigned reading:** OpenStax *Introduction to Philosophy* (2022), [5.1](https://openstax.org/books/introduction-philosophy/pages/5-1-philosophical-methods-for-discovering-truth), [5.2](https://openstax.org/books/introduction-philosophy/pages/5-2-logical-statements), [5.3](https://openstax.org/books/introduction-philosophy/pages/5-3-arguments), [5.4](https://openstax.org/books/introduction-philosophy/pages/5-4-types-of-inferences), and [5.5](https://openstax.org/books/introduction-philosophy/pages/5-5-informal-fallacies), complete. Sessions 2–3 already read 5.2–5.3 and the deductive portion of 5.4; use the 50 minutes for 5.1, the remainder of 5.4, and review. Section 5.5 belongs to the [two-hour practical packet](../practical-reasoning.md). Read the packet's cases and complete its independent check inside those two hours. Soundness is explained in [Session 3](../sessions/03.md), with its separately identified textbook support.

**Teaching explanation:** An argument offers premises for a conclusion. A reconstruction makes the inferential dependency inspectable: mark supplied premises and bracket your additions. A valid deductive argument excludes true premises with a false conclusion; this is a relation among statements, not praise for its subject matter. Soundness adds premise truth. An invalid argument may accidentally end at a true conclusion. In inductive reasoning the conclusion extends beyond the premises; test the relevance and strength of evidence rather than demanding deductive certainty from every useful inference.

For “P only if Q,” Q is necessary for P: P cannot obtain without Q. For “P if Q,” Q is sufficient for P. A definition claiming both directions needs both tests. A counterexample to a proposed sufficient condition meets that condition while missing the defined property. An alleged exception that changes the definition halfway through does no work. Charitable reconstruction makes a premise plausible enough to test; it must not silently replace the original claim.

**Worked example, invented:** Every item in cabinet A is catalogued; this map is in A; therefore it is catalogued. The inference preserves truth if the premises hold, even if the first premise actually fails. “This map is catalogued, therefore it is in A” requires an additional exclusivity premise: catalogued items may be elsewhere.

**Practice and outputs:** Retain Session 2's first four reconstructions. Add (5) “Every rule that treats similar cases differently needs justification. This rule treats similar cases differently. Therefore it needs justification”; and (6) “If Lea borrowed this copy, its catalogue record would show a loan. The record shows a loan. Therefore Lea borrowed this copy.” Number premises, identify the conclusion, and state a countercase or why none is possible with the premises true. Count Session 3's two supplied and two original condition examples if each explains its test. Finish a 200-word validity/soundness explanation with one invented example of each distinction. The practical packet analyses support these outputs, not extra gate items.

**Independent changed case:** “Every authorised curator has an access token. Dani has no access token. So Dani is not an authorised curator.” Compare with “Dani has a token; so Dani is authorised.” Explain both in 150–200 words and test “a token is sufficient for authorisation.” Criteria: preserve the stipulated premise, distinguish directions, and justify any countercase. Do not consult feedback during the attempt.

**Repair and retrieval:** If a countercase changes a premise, list the truth of each premise and conclusion separately and rebuild it. Module 3 begins with five minutes recalling necessity/sufficiency within its reading block. **Next:** Module 3's source and paragraph work.
