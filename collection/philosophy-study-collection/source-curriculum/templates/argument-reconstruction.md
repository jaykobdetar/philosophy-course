# Argument reconstruction format

**Source:** author, work, location (standard reference numbers)

**Standard form**

- P1. ...
- P2. ...
- [P3. ...] (square brackets mark a premise you've added that the text doesn't state)
- C. ...

**Inference.** Is the argument valid as reconstructed? If not, what's missing?

**Charity check.** Is this the strongest reasonable version? List any repairs, and why the author would accept them.

**Weakest premise.** Which premise is most open to doubt, and why?

**Counterexample.** A case where the premises seem true and the conclusion false, or a case against the weakest premise.
