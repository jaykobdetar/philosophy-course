# Mastery dashboard

Alongside grades, the learner's skills are tracked on seven dimensions, each scored from 0 to 4. The Examiner updates scores from evidence (gates, practice grading, confirmation checks), and the Director records them in `learner/record/dashboard.md`.

| Dimension | 0 | 1 | 2 | 3 | 4 |
|---|---|---|---|---|---|
| Critical reading | No usable reconstruction | Notices claims but misses structure | Mostly accurate with help | Independently accurate | Handles ambiguity and competing interpretations |
| Argumentation | Assertions only | Reasons weakly connected | Basic argument works | Strong argument with objection and reply | Anticipates implications and revises strategically |
| Writing | Unstructured | Basic exposition | Clear but uneven | Coherent analytic writing | Economical and precise, structured like published work |
| Logic | No competence | Recognizes forms | Solves routine problems with help | Independent basic proficiency | Transfers formal tools to philosophy |
| Historical understanding | Anachronistic or inaccurate | Isolated facts | Basic context | Accurate comparative understanding | Connects historical arguments to later debates without distortion |
| Research | Depends on unverified web sources | Finds sources but can't assess them | Uses the SEP and bibliographies | Uses PhilPapers and scholarly literature independently | Maps a debate and identifies a real research question |
| Oral defense | Can't explain own argument | Repeats prepared claims | Answers basic questions | Defends and revises under questioning | Handles novel objections with precision |

The thresholds each gate requires are in [gates.md](gates.md).

## Completing the program

The program is complete when all 15 units are mastered and the dashboard shows an average of at least 3 across the seven dimensions, with no dimension below 2, and with critical reading, argumentation, and writing at 3 or above. This is the project's own standard, not an institutional rule.
